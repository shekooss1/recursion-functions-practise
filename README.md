# Python Recursion Practice

A personal collection of Python recursion exercises focused on developing problem-solving skills and understanding recursive algorithms.

## About

This repository documents my journey learning recursion in Python, starting with basic recursive functions and gradually moving toward more advanced algorithms.

My goal is to understand the logic behind each problem, implement solutions independently, handle edge cases, and analyze time and space complexity.

## Topics

- Base cases and recursive cases
- Recursive calls and the call stack
- Accumulator-based recursion
- Working with numbers, strings, and lists
- Recursive searching and comparisons
- Divide and conquer
- Nested recursion
- Backtracking

## How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-recursion-practice.git
```

Enter the project directory:

```bash
cd python-recursion-practice
```

Run the Python file:

```bash
python recursion_practice.py
```

Depending on your system, you may need to use `python3` instead of `python`.

## My Learning Process

For each exercise, I aim to:

1. Understand the problem and its constraints.
2. Identify the base case.
3. Define the recursive case.
4. Trace the recursive calls.
5. Test normal cases and edge cases.
6. Analyze time and space complexity.
7. Implement the solution independently.
